# Archiwum - podstrona System CRM (chat 11)

Kopie tekstowe plików sekcji 2 („Nic już nie ginie”) i 5 (moduły) ze stanu z 2026-10-05, tuż przed usunięciem
niewybranych wersji przy optymalizacji wydajności. Właściciel wskazał „Kanały” (sekcja 2) i „W dół” (sekcja 5);
usunięte: „Lejek”, „Karta klienta”, „Rośnie”, „Menu rośnie”.

Pliki mają rozszerzenie `.txt`, żeby nie wchodziły do kompilacji ani lintera. Żeby przywrócić wersję: skopiować
plik sceny (`lead-funnel.tsx`, `lead-card.tsx`, `mods-rise.tsx`, `mods-menu.tsx`) z powrotem do
`app/(pl)/uslugi/strony-www/system-crm/`, a z kopii `lead-kit.tsx`, `lead.css`, `mods-ui.tsx`, `mods.css` i słowników
(`system-crm-lead.ts`, `system-crm-mods.ts`) przenieść brakujące części. Kopie są sprzed dostosowania tych wersji do
telefonu i sprzed zmiany sposobu odsłaniania na „na czas” - wymagałyby tych samych poprawek co wersje wybrane.

Opis wersji i decyzje właściciela: `docs/podstrony/usluga-system-crm.md`.
